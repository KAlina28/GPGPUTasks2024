(b) ответ: не будет coalesced

```
data[get_local_id(1) + get_local_size(1) * get_local_id(0)] = 1.0f;
```

решение: заметим, что внутри одно wrap у нас индекс будет таким get_local_id(1) + get_local_size(1) * get_local_id(0) = const + 32 * get_local_id(0), то есть соседние индексы будут отличаться на 32 по номеру, значит на 32 * 4 = 128 по байтам, тогда никакие 2 индекса одного wrap не будут в одной кэш линии. Значит потребуется колво кэш линий равное колву возможных индексов - это 32*32 = 1024
